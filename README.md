# Job Portal Web Application

A full-stack Job Portal Web Application developed using the MERN Stack.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Features

- User Registration
- User Login
- Job Listing
- Job Search
- Job Posting
- Job Applications
- Application Management

## Project Structure

job-portal/
│
├── frontend/
│   └── React application
│
└── backend/
    └── Node.js and Express API
